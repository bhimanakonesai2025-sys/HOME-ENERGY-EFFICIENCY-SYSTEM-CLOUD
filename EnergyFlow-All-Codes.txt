===== ./README.md =====
# EnergyFlow – Cloud-Based Home Energy Efficiency Monitoring System

## Problem statement

Households usually receive electricity bills showing overall consumption, but this does not provide clear appliance-wise visibility. EnergyFlow is designed to collect appliance-level energy readings, store them in cloud services, analyze consumption, and present understandable energy-efficiency insights.

## Final architecture

Real measured public energy dataset
        ↓
VM / cloud ingestion process
        ↓
EC2 VM running Node.js + Express
        ↓
Amazon DynamoDB
        ↓
Analytics + RAG
        ↓
Web dashboard

The same ingestion API is hardware-ready for a future ESP32/sensor source. Physical hardware is not required for this version.

## Why this is a cloud project

- Amazon EC2 provides the virtual machine/application compute layer.
- Amazon DynamoDB provides managed cloud storage with scalable throughput.
- The API is stateless and can run in multiple Node.js worker processes.
- Readings are partitioned by homeId and indexed by deviceId/timestamp.
- Authentication protects dashboard APIs.
- A dedicated ingestion key protects automated data ingestion.
- The dashboard can be accessed remotely after EC2 deployment.

## Data source

The final data source should be a real measured dataset, not Math.random().

This project is prepared for the UK-DALE dataset, which contains appliance-by-appliance and whole-home electricity demand from five UK homes at approximately six-second resolution.

The project does not claim that the measurements were collected by your own hardware. They are published dataset measurements used as the input stream.

## Local development

1. Copy `.env.example` to `.env`.
2. Keep:
   STORAGE_MODE=local
3. Install packages:
   npm install
4. Start:
   npm start
5. Open:
   http://localhost:5000/register.html
6. Register an account.

Local mode stores development data in data/local-db.json.

## AWS setup

Create DynamoDB tables:

npm run setup:aws

For local AWS CLI configuration, configure credentials with the AWS CLI.

For EC2, prefer attaching an IAM role to the EC2 instance rather than storing long-lived access keys on the server.

Then set:

STORAGE_MODE=dynamodb
AWS_REGION=your-region
JWT_SECRET=your-long-secret
INGEST_API_KEY=your-long-ingestion-secret

## UK-DALE import

Place House 1 labels.dat and the appliance channel files under:

data/ukdale/house_1/

Get your registered homeId from the browser developer console or from the JWT user object.

Then:

node scripts/import-ukdale.js --home YOUR_HOME_ID --limit 500

The importer converts measured appliance power in watts into interval energy in kWh.

## EC2 deployment outline

On an Ubuntu EC2 instance:

sudo apt update
sudo apt install -y git nodejs npm

Clone/copy the project, then:

npm install
cp .env.example .env
nano .env

Set STORAGE_MODE=dynamodb and the AWS region.

Create tables:

npm run setup:aws

Start the server:

npm start

For a persistent production process, install PM2:

sudo npm install -g pm2
pm2 start ecosystem.config.js
pm2 save
pm2 startup

Open TCP port 5000 in the EC2 security group if you are directly demonstrating the application on port 5000.

For a production-style deployment, put Nginx in front of Node.js and expose HTTPS on port 443.

## Important presentation wording

Say:

"Because physical sensing hardware was not available, we used a real measured appliance-level energy dataset as the input source. The data ingestion layer is deployed on a cloud VM and uses the same API contract that future hardware can use. The application stores and analyzes the readings in a scalable cloud database and presents appliance-wise energy insights through the dashboard."

Do not say the dataset values were measured by your own hardware.
Do not use Math.random() in the final demonstration.

===== ./knowledge/energy-knowledge.txt =====
AIR CONDITIONER
Air conditioners can be major household electricity consumers. Reducing unnecessary operating time can reduce electricity consumption. When comfortable, setting the thermostat slightly higher can reduce cooling energy. Keep doors and windows closed while cooling. Clean filters regularly because blocked filters can reduce airflow and efficiency. Prefer efficient cooling modes when available.

REFRIGERATOR
Refrigerators operate for long periods and therefore can contribute significantly to household electricity use. Keep the door closed as much as possible, maintain suitable temperature settings, and allow sufficient airflow around the appliance. Regular maintenance can support efficient operation.

TELEVISION
Televisions generally consume less power than major heating or cooling appliances, but long operating hours can increase their cumulative consumption. Turn the television off when it is not being used rather than leaving it running unnecessarily.

WASHING MACHINE
Washing machines can have high power demand during heating and some operating stages. Prefer full loads when appropriate, use efficient or lower-temperature cycles when suitable, and avoid unnecessary repeated cycles.

LIGHTING
LED lighting generally requires less electricity than older lighting technologies. Turn lights off when areas are unoccupied and use daylight when practical.

ENERGY ANALYSIS
Energy consumed can be calculated as:
Energy (kWh) = Power (W) × Time (hours) / 1000.

Historical energy readings can be analyzed to identify high-consumption devices and usage patterns. Recommendations should prioritize devices that contribute substantially to total consumption.

RAG SAFETY
The system should provide evidence-based energy-saving suggestions. It should not claim that an appliance is defective unless there is sufficient evidence. High consumption alone does not prove a hardware fault.

===== ./middleware/auth.js =====
const jwt = require("jsonwebtoken");

function getToken(req) {
  const header = req.headers.authorization || "";

  if (header.startsWith("Bearer ")) {
    return header.substring(7);
  }

  return null;
}

function requireAuth(req, res, next) {
  const token = getToken(req);

  if (!token) {
    return res.status(401).json({ message: "Authentication token required." });
  }

  try {
    const payload = jwt.verify(token, process.env.JWT_SECRET);

    req.user = payload;
    next();
  } catch (error) {
    return res.status(401).json({ message: "Invalid or expired token." });
  }
}

function requireIngestionKey(req, res, next) {
  const key = req.headers["x-ingest-key"];

  if (!process.env.INGEST_API_KEY) {
    return res.status(500).json({ message: "INGEST_API_KEY is not configured." });
  }

  if (!key || key !== process.env.INGEST_API_KEY) {
    return res.status(401).json({ message: "Invalid ingestion key." });
  }

  next();
}

module.exports = { requireAuth, requireIngestionKey };

===== ./public/script.js =====
const token = localStorage.getItem("energyflow_token");

if (!token) {
  window.location.href = "/login.html";
}

function headers() {
  return {
    "Content-Type": "application/json",
    "Authorization": `Bearer ${token}`
  };
}

async function api(url, options = {}) {
  const response = await fetch(url, {
    ...options,
    headers: {
      ...headers(),
      ...(options.headers || {})
    }
  });

  if (response.status === 401) {
    localStorage.removeItem("energyflow_token");
    localStorage.removeItem("energyflow_user");
    window.location.href = "/login.html";
    throw new Error("Session expired.");
  }

  const data = await response.json();

  if (!response.ok) {
    throw new Error(data.message || "Request failed.");
  }

  return data;
}

function money(value) {
  return `₹${Number(value || 0).toFixed(2)}`;
}

function energy(value) {
  return `${Number(value || 0).toFixed(3)} kWh`;
}

function formatTime(value) {
  const d = new Date(value);
  if (Number.isNaN(d.getTime())) return "—";
  return d.toLocaleString();
}

function set(id, value) {
  const el = document.getElementById(id);
  if (el) el.textContent = value;
}

async function checkCloud() {
  const el = document.getElementById("cloudStatus");
  if (!el) return;

  try {
    const r = await fetch("/api/health");
    const data = await r.json();
    el.textContent = `Cloud API • ${data.storageMode}`;
  } catch {
    el.textContent = "Cloud API unavailable";
  }
}

function renderBars(containerId, devices, total) {
  const container = document.getElementById(containerId);
  if (!container) return;

  if (!devices.length) {
    container.innerHTML = `<p class="muted">No energy readings have been imported yet.</p>`;
    return;
  }

  const max = Math.max(...devices.map(d => Number(d.energyConsumed || 0)), 0.000001);

  container.innerHTML = devices.map(d => {
    const share = total ? (Number(d.energyConsumed) / total) * 100 : 0;
    const width = (Number(d.energyConsumed) / max) * 100;

    return `<div class="bar-row">
      <div>${escapeHtml(d.deviceName)}</div>
      <div class="bar"><span style="width:${Math.max(2, width)}%"></span></div>
      <div>${share.toFixed(1)}%</div>
    </div>`;
  }).join("");
}

function escapeHtml(value) {
  return String(value)
    .replaceAll("&", "&amp;")
    .replaceAll("<", "&lt;")
    .replaceAll(">", "&gt;")
    .replaceAll('"', "&quot;")
    .replaceAll("'", "&#039;");
}

async function loadDashboard() {
  const totalEnergyEl = document.getElementById("totalEnergy");
  if (!totalEnergyEl) return;

  const [summary, readings] = await Promise.all([
    api("/api/energy/summary"),
    api("/api/energy/readings?limit=20")
  ]);

  set("totalEnergy", energy(summary.totalEnergy));
  set("estimatedCost", money(summary.estimatedCost));
  set("applianceCount", summary.applianceCount);
  set("highUsageCount", summary.highUsageCount);

  renderBars("energyBars", summary.devices, Number(summary.totalEnergy));

  const insight = document.getElementById("smartInsight");

  if (insight) {
    if (summary.highestConsumer) {
      insight.innerHTML = `
        <p><strong>${escapeHtml(summary.highestConsumer.deviceName)}</strong>
        is currently the largest energy contributor.</p>
        <p>Consumption: <strong>${energy(summary.highestConsumer.energyConsumed)}</strong></p>
        <p>Contribution: <strong>${summary.highestConsumer.contribution}%</strong></p>
        <p class="muted">The system prioritizes this device for energy-efficiency analysis.</p>`;
    } else {
      insight.innerHTML = `<p class="muted">Import real energy readings to generate insights.</p>`;
    }
  }

  const body = document.getElementById("readingsBody");

  if (body) {
    body.innerHTML = readings.readings.length
      ? readings.readings.map(r => `
        <tr>
          <td>${escapeHtml(r.deviceName)}</td>
          <td>${Number(r.power).toFixed(2)} W</td>
          <td>${Number(r.energyConsumed).toFixed(6)} kWh</td>
          <td>${formatTime(r.timestamp)}</td>
          <td>${escapeHtml(r.source || "—")}</td>
        </tr>`).join("")
      : `<tr><td colspan="5" class="muted">No readings yet.</td></tr>`;
  }
}

async function loadAnalytics() {
  const target = document.getElementById("analyticsBars");
  if (!target) return;

  const summary = await api("/api/energy/summary");
  const rag = await api("/api/energy/rag-analysis");

  renderBars("analyticsBars", summary.devices, Number(summary.totalEnergy));

  const analysis = document.getElementById("analysisText");

  if (analysis) {
    analysis.innerHTML = summary.highestConsumer
      ? `<p>Total analyzed energy: <strong>${energy(summary.totalEnergy)}</strong></p>
         <p>Highest consumer: <strong>${escapeHtml(summary.highestConsumer.deviceName)}</strong></p>
         <p>Share: <strong>${summary.highestConsumer.contribution}%</strong></p>
         <p class="muted">High usage is flagged when a device contributes at least 20% of the analyzed energy.</p>`
      : `<p class="muted">No readings available.</p>`;
  }

  const ragText = document.getElementById("ragText");

  if (ragText) {
    if (!rag.ragContext.length) {
      ragText.innerHTML = `<p class="muted">No RAG results yet.</p>`;
    } else {
      ragText.innerHTML = rag.ragContext.map(item => `

const fs = require("fs");
const path = require("path");

const knowledgePath = path.join(
  __dirname,
  "knowledge",
  "energy-knowledge.txt"
);

function loadKnowledge() {
  if (!fs.existsSync(knowledgePath)) {
    return "";
  }

  return fs.readFileSync(knowledgePath, "utf8");
}

function splitSections(text) {
  return text
    .split(/\n\s*\n/)
    .map(s => s.trim())
    .filter(Boolean);
}

function normalize(text) {
  return String(text || "").toLowerCase();
}

function getRagRecommendations(deviceName) {
  const sections = splitSections(loadKnowledge());
  const query = normalize(deviceName);

  const direct = sections.filter(section =>
    normalize(section).includes(query)
  );

  const general = sections.filter(section =>
    /energy|efficien|consumption|historical|recommend/i.test(section)
  );

  const unique = [];
  const seen = new Set();

  for (const section of [...direct, ...general]) {
    const key = section.toLowerCase();

    if (!seen.has(key)) {
      seen.add(key);
      unique.push(section);
    }

    if (unique.length >= 5) break;
  }

  return unique;
}

module.exports = {
  getRagRecommendations,
  loadKnowledge
};

  let energyConsumed = Number(body.energyConsumed);

  if (!Number.isFinite(power) || power < 0) {
    throw new Error("power must be a non-negative number.");

/**
 * Import real appliance-level measurements from UK-DALE.
 *
 * Expected files:
 * data/ukdale/house_1/labels.dat
 * data/ukdale/house_1/channel_<N>.dat
 *
 * UK-DALE records appliance power approximately every 6 seconds.
 * The importer converts power in watts into kWh for each interval.
 *
 * Usage:
 *   node scripts/import-ukdale.js --home HOME_ID --limit 1000
 *
 * The HOME_ID must belong to a registered EnergyFlow account.
 *
 * You can use STORAGE_MODE=local for development or
 * STORAGE_MODE=dynamodb on the cloud VM.
 */

require("dotenv").config();

const fs = require("fs");
const path = require("path");
const readline = require("readline");
const crypto = require("crypto");

const { createReading, createAppliance } = require("../services/db");

const HOUSE_DIR = path.join(
  __dirname,
  "..",
  "data",
  "ukdale",
  "house_1"
);

const wantedNames = [
  "washing_machine",
  "washing machine",
  "fridge",
  "fridge_freezer",
  "tv",
  "kettle",
  "dishwasher",
  "dish_washer",
  "microwave",
  "toaster"
];

function arg(name, fallback = null) {
  const index = process.argv.indexOf(name);
  return index >= 0 ? process.argv[index + 1] : fallback;
}

function cleanName(name) {
  return name
    .trim()
    .replace(/^['"]|['"]$/g, "")
    .replace(/[_-]+/g, " ")
    .replace(/\s+/g, " ");
}

function shouldImport(name) {
  const normalized = name.toLowerCase().replace(/\s+/g, "_");
  return wantedNames.some(w => w === normalized || w === name.toLowerCase());
}

function parseLabels() {
  const labelsPath = path.join(HOUSE_DIR, "labels.dat");

  if (!fs.existsSync(labelsPath)) {
    throw new Error(
      `Missing ${labelsPath}. Download the UK-DALE house_1 labels.dat file first.`
    );
  }

  const text = fs.readFileSync(labelsPath, "utf8");

  const result = [];

  for (const line of text.split(/\r?\n/)) {
    if (!line.trim()) continue;

    const parts = line.split(/\s+/);
    const channel = Number(parts.shift());

    if (!Number.isFinite(channel)) continue;

    const name = cleanName(parts.join(" "));

    if (shouldImport(name)) {
      result.push({
        channel,
        name
      });
    }
  }

  return result;
}

async function importChannel(homeId, channel, deviceName, limit) {
  const filePath = path.join(
    HOUSE_DIR,
    `channel_${channel}.dat`
  );

  if (!fs.existsSync(filePath)) {
    console.log(`Skipping ${deviceName}: ${filePath} not found`);
    return 0;
  }

  const deviceId =
    `UKDALE-H1-${deviceName.toUpperCase().replace(/[^A-Z0-9]+/g, "_")}`;

  await createAppliance({
    homeId,
    deviceId,
    name: deviceName,
    applianceId: `ukdale-${channel}`,
    source: "UK-DALE",
    updatedAt: new Date().toISOString()
  });

  const rl = readline.createInterface({
    input: fs.createReadStream(filePath),
    crlfDelay: Infinity
  });

  let previousTimestamp = null;
  let imported = 0;

  for await (const line of rl) {
    if (imported >= limit) break;
    if (!line.trim()) continue;

    const parts = line.trim().split(/\s+/);

    const unixSeconds = Number(parts[0]);
    const power = Number(parts[1]);

    if (!Number.isFinite(unixSeconds) || !Number.isFinite(power)) {
      continue;
    }

    const timestamp = new Date(unixSeconds * 1000);

    let intervalSeconds = 6;

    if (previousTimestamp !== null) {
      const diff = unixSeconds - previousTimestamp;

      if (diff > 0 && diff <= 3600) {
        intervalSeconds = diff;
      }
    }

    previousTimestamp = unixSeconds;

    const energyConsumed =
      (Math.max(power, 0) * intervalSeconds) / 3600000;

    const reading = {
      homeId,
      deviceId,
      deviceName,
      power: Number(Math.max(power, 0).toFixed(3)),
      energyConsumed: Number(energyConsumed.toFixed(8)),
      timestamp: timestamp.toISOString(),
      readingId: crypto.randomUUID(),
      readingKey: `${timestamp.toISOString()}#${crypto.randomUUID()}`,
      source: "UK-DALE-real-dataset",
      createdAt: new Date().toISOString()
    };

    await createReading(reading);
    imported++;
  }

  console.log(`✓ ${deviceName}: imported ${imported} readings`);
  return imported;
}

async function main() {
  const homeId = arg("--home");

  if (!homeId) {
    throw new Error("Provide --home HOME_ID");
  }

  const limit = Math.min(
    Math.max(Number(arg("--limit", "500")), 1),
    5000
  );

  console.log("==========================================");
  console.log(" EnergyFlow - UK-DALE Importer");
  console.log("==========================================");
  console.log(`Storage: ${process.env.STORAGE_MODE || "local"}`);
  console.log(`Home: ${homeId}`);
  console.log(`Limit per appliance: ${limit}`);

  const channels = parseLabels();

  if (!channels.length) {
    throw new Error(
      "No supported appliance channels were found in labels.dat."
    );
  }

  console.log("Appliances found:", channels);

  let total = 0;

  for (const item of channels) {
    total += await importChannel(
      homeId,
      item.channel,
      item.name,
      limit
    );
  }

  console.log(`Finished. Total imported readings: ${total}`);
}

main().catch(error => {
  console.error("UK-DALE import failed:", error);
  process.exit(1);
});

    AttributeDefinitions: [{ AttributeName: "homeId", AttributeType: "S" }]
  },
  {
    TableName: TABLES.appliances,
    KeySchema: [
      { AttributeName: "homeId", KeyType: "HASH" },
      { AttributeName: "deviceId", KeyType: "RANGE" }
    ],
    AttributeDefinitions: [
      { AttributeName: "homeId", AttributeType: "S" },
      { AttributeName: "deviceId", AttributeType: "S" }
    ]
  },
  {
    TableName: TABLES.readings,
    KeySchema: [
      { AttributeName: "homeId", KeyType: "HASH" },
      { AttributeName: "readingKey", KeyType: "RANGE" }
    ],
    AttributeDefinitions: [
      { AttributeName: "homeId", AttributeType: "S" },
      { AttributeName: "readingKey", AttributeType: "S" },
      { AttributeName: "deviceId", AttributeType: "S" },
      { AttributeName: "timestamp", AttributeType: "S" }
    ],
    GlobalSecondaryIndexes: [
      {
        IndexName: "DeviceTimestampIndex",
        KeySchema: [
          { AttributeName: "deviceId", KeyType: "HASH" },
          { AttributeName: "timestamp", KeyType: "RANGE" }
        ],
        Projection: { ProjectionType: "ALL"
        }
      }
    ]
  }
];

async function tableExists(name) {
  try {
    await client.send(new DescribeTableCommand({ TableName: name }));
    return true;
  } catch (error) {
    if (error.name === "ResourceNotFoundException") {
      return false;
    }
    throw error;
  }
}

async function main() {
  console.log(`AWS region: ${region}`);

  for (const definition of definitions) {
    const exists = await tableExists(definition.TableName);

    if (exists) {
      console.log(`✓ ${definition.TableName} already exists`);
      continue;
    }

    await client.send(new CreateTableCommand({
      ...definition,
      BillingMode: "PAY_PER_REQUEST"
    }));

    console.log(`✓ Created ${definition.TableName}`);
  }

  console.log("DynamoDB setup complete.");
}

main().catch(error => {
  console.error("DynamoDB setup failed:", error);
  process.exit(1);
});

const fs = require("fs");
const path = require("path");
const crypto = require("crypto");

const {
  PutCommand,
  GetCommand,
  QueryCommand,
  ScanCommand
} = require("@aws-sdk/lib-dynamodb");

const { docClient } = require("../config/aws");

const MODE = (process.env.STORAGE_MODE || "local").toLowerCase();

const TABLES = {
  users: "EnergyFlowUsers",
  homes: "EnergyFlowHomes",
  appliances: "EnergyFlowAppliances",
  readings: "EnergyFlowReadings"
};

const localPath = path.join(__dirname, "..", "data", "local-db.json");

function id(prefix = "") {
  return `${prefix}${crypto.randomUUID()}`;
}

function emptyDb() {
  return {
    users: [],
    homes: [],
    appliances: [],
    readings: []
  };
}

function readLocal() {
  if (!fs.existsSync(localPath)) {
    fs.mkdirSync(path.dirname(localPath), { recursive: true });
    fs.writeFileSync(localPath, JSON.stringify(emptyDb(), null, 2));
  }

  return JSON.parse(fs.readFileSync(localPath, "utf8"));
}

function writeLocal(db) {
  fs.mkdirSync(path.dirname(localPath), { recursive: true });
  fs.writeFileSync(localPath, JSON.stringify(db, null, 2));
}

function clone(obj) {
  return JSON.parse(JSON.stringify(obj));
}

async function createUser(user) {
  if (MODE === "local") {
    const db = readLocal();
    db.users.push(clone(user));
    writeLocal(db);
    return user;
  }

  await docClient.send(new PutCommand({
    TableName: TABLES.users,
    Item: user
  }));

  return user;
}

async function getUserByEmail(email) {
  const normalized = email.toLowerCase().trim();

  if (MODE === "local") {
    const db = readLocal();
    return db.users.find(u => u.email === normalized) || null;
  }

  const result = await docClient.send(new GetCommand({
    TableName: TABLES.users,
    Key: { email: normalized }
  }));

  return result.Item || null;
}

async function createHome(home) {
  if (MODE === "local") {
    const db = readLocal();
    db.homes.push(clone(home));
    writeLocal(db);
    return home;
  }

  await docClient.send(new PutCommand({
    TableName: TABLES.homes,
    Item: home
  }));

  return home;
}

async function getHome(homeId) {
  if (MODE === "local") {
    const db = readLocal();
    return db.homes.find(h => h.homeId === homeId) || null;
  }

  const result = await docClient.send(new GetCommand({
    TableName: TABLES.homes,
    Key: { homeId }
  }));

  return result.Item || null;
}

async function createAppliance(appliance) {
  if (MODE === "local") {
    const db = readLocal();
    const existingIndex = db.appliances.findIndex(
      a => a.homeId === appliance.homeId && a.deviceId === appliance.deviceId
    );

    if (existingIndex >= 0) {
      db.appliances[existingIndex] = { ...db.appliances[existingIndex], ...appliance };
    } else {
      db.appliances.push(clone(appliance));
    }

    writeLocal(db);
    return appliance;
  }

  await docClient.send(new PutCommand({
    TableName: TABLES.appliances,
    Item: appliance
  }));

  return appliance;
}

async function listAppliances(homeId) {
  if (MODE === "local") {
    const db = readLocal();
    return db.appliances.filter(a => a.homeId === homeId);
  }

  const result = await docClient.send(new QueryCommand({
    TableName: TABLES.appliances,
    KeyConditionExpression: "homeId = :homeId",
    ExpressionAttributeValues: { ":homeId": homeId }
  }));

  return result.Items || [];
}

async function createReading(reading) {
  if (MODE === "local") {
    const db = readLocal();
    db.readings.push(clone(reading));

    // Keep local development reasonably small.
    if (db.readings.length > 20000) {
      db.readings = db.readings.slice(-20000);
    }

    writeLocal(db);
    return reading;
  }

  const item = {
    ...reading,
    readingKey: reading.readingKey || `${reading.timestamp}#${reading.readingId || id("reading-")}`
  };

  await docClient.send(new PutCommand({
    TableName: TABLES.readings,
    Item: item
  }));

  return item;
}

async function listReadings(homeId, limit = 500) {
  if (MODE === "local") {
    const db = readLocal();

    return db.readings
      .filter(r => r.homeId === homeId)
      .sort((a, b) => new Date(b.timestamp) - new Date(a.timestamp))
      .slice(0, limit);
  }

  const result = await docClient.send(new QueryCommand({
    TableName: TABLES.readings,
    KeyConditionExpression: "homeId = :homeId",
    ExpressionAttributeValues: { ":homeId": homeId },
    ScanIndexForward: false,
    Limit: limit
  }));

  return result.Items || [];
}

async function listAllReadings(homeId, maxItems = 5000) {
  if (MODE === "local") {
    const db = readLocal();

    return db.readings
      .filter(r => r.homeId === homeId)
      .sort((a, b) => new Date(b.timestamp) - new Date(a.timestamp))
      .slice(0, maxItems);
  }

  const items = [];
  let ExclusiveStartKey;

  do {
    const result = await docClient.send(new QueryCommand({
      TableName: TABLES.readings,
      KeyConditionExpression: "homeId = :homeId",
      ExpressionAttributeValues: { ":homeId": homeId },
      ExclusiveStartKey,
      ScanIndexForward: false,
      Limit: Math.min(1000, maxItems - items.length)
    }));

    items.push(...(result.Items || []));
    ExclusiveStartKey = result.LastEvaluatedKey;

    if (items.length >= maxItems) break;
  } while (ExclusiveStartKey);

  return items.slice(0, maxItems);
}

async function getReadingCount() {
  if (MODE === "local") {
    return readLocal().readings.length;
  }

  // This is only for a health/admin display.
  const result = await docClient.send(new ScanCommand({
    TableName: TABLES.readings,
    Select: "COUNT"
  }));

  return result.Count || 0;
}
